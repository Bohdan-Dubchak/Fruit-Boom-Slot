# Fruit Boom Slot

Демонстраційний фруктовий слот-автомат (5 барабанів × 3 ряди), реалізований на **TypeScript** з рендерингом через **PixiJS 8**, анімаціями на **GSAP** та звуком через **Howler.js**. Проєкт зібраний за допомогою **Vite**.

## Можливості

-  5 барабанів, 3 ряди, зважена генерація символів (`WeightedSpinGenerator`)
-  Система балансу та ставок (`WalletManager`, `BetManager`) з утриманням ставки при затиснутій кнопці +/-
-  Розрахунок виграшів по горизонтальних та вертикальних лініях (`WinManager`) на основі таблиці виплат
-  Підсвітка виграшних ліній та win-анімації (`WinHighlight`, `ReelAnimations`, `SymbolsAnimations`)
-  Автоспін (Auto Spin)
-  Керування музикою та звуковими ефектами, вкл./викл. звуку
-  Панель налаштувань (музика, звук, повноекранний режим)
-  Мультимовність — інтерфейс перемикається між англійською, німецькою та українською (`LanguageManager`, `translations.ts`)
-  Адаптивна роздільна здатність під різні екрани (`ResolutionManager`)
-  Індикатор джекпоту (`JackpotDisplay`)
-  Завантажувальний екран із прогрес-баром та обробкою критичних ассетів (`Loader`, `LoadingScene`)

## Встановлення та запуск


```bash
# Встановити залежності
npm install

# Запустити dev-сервер (Vite)
npm run dev

# Зібрати production-версію (перевірка типів + збірка)
npm run build

# Переглянути production-збірку локально
npm run preview
```


## Як грати

1. Дочекайтеся завершення завантаження ассетів.
2. Налаштуйте розмір ставки кнопками **+ / −** (можна утримувати для швидкої зміни).
3. Натисніть кнопку **Spin**, щоб запустити барабани.
4. Увімкніть **Auto Spin** для автоматичних спінів поспіль.
5. Відкрийте **налаштування** (⚙️), щоб керувати музикою, звуком та повноекранним режимом.
6. Натисніть на прапорець, щоб змінити мову інтерфейсу (EN / DE / UA).

## Ігрова логіка

- **Генерація барабанів**: `WeightedSpinGenerator` формує "пул" символів на основі ваг із `SYMBOLS_IDS` та випадково обирає символи для кожної позиції матриці за допомогою власного лінійного конгруентного генератора `RNG`.
- **Перевірка виграшів**: `WinManager` перевіряє як горизонтальні (по рядах), так і вертикальні (по барабанах, повний збіг) комбінації однакових символів і зіставляє довжину серії з таблицею виплат `payTable`.
- **Виплата**: сума виграшу = сумарний множник усіх виграшних ліній × поточна ставка.

> ⚠️ Це навчальний/демонстраційний проєкт. RNG є детермінованим (linear congruential generator) і не призначений для реальних грошових ставок чи сертифікованих азартних ігор.
